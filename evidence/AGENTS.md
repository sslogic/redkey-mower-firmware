# Purpose
- Preserve searchable static evidence behind documented firmware and app findings.

# Local Contracts
- Retain addresses, constants, instruction excerpts and artifact hashes.
- Remove personal paths and runtime/device-specific observations. Do not include entire APKs or decompiled package trees.
- Evidence is static unless explicitly stated otherwise. Image checksums do not establish manufacturer authenticity.

# Verification
- Cross-check evidence hashes and addresses against the unchanged original image and documented source identity.
